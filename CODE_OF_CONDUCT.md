# Code of Conduct

## Scope

This code applies to Issues, pull requests, reviews, Discussions, and other public collaboration around this repository.

## Expected conduct

Communicate professionally and respectfully. Critique claims, evidence structures, contracts, code, and methods rather than people. Protect private information, respect attribution and third-party rights, and keep uncertainty explicit. Harassment, discrimination, threats, doxxing, impersonation, fabricated evidence, deliberate deception, and repeated disruption are unacceptable.

## Evidence-aware collaboration

Keep execution state, evidence status, source authority, correctness, scientific validity, external methods, proposals, and unknown state distinct. Do not present unexecuted checks as passed or silently rewrite historical maintenance records to match later knowledge.

## Sensitive information

Do not publish credentials, private data, or unpublished exploit details. Follow `SECURITY.md` for security-sensitive reports. Conduct concerns containing private information should use an available private contact route rather than a public Issue.

## Moderation

The repository maintainer may edit, hide, remove, lock, or reject contributions that violate these standards or materially undermine repository integrity. Repeated or serious violations may result in participation restrictions.

The repository owner retains final moderation and merge authority.
