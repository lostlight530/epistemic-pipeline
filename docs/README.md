# Documentation Taxonomy

This directory classifies the repository's research, explanatory, contract, example, metadata, and maintenance/audit materials into three reading classes. It is not a complete filesystem inventory, and it does not relocate canonical runtime or configuration entrypoints by itself.

1. [Source and explanation](01-source-and-explanation/README.md) — executable implementation, tests, and documents that explain current behavior.
2. [Examples and contracts](02-examples-and-contracts/README.md) — machine/project contracts, examples, operator guidance, usage constraints, and repository metadata.
3. [Maintenance and audit](03-maintenance-and-audit/README.md) — maintenance rules/configuration, dated reconciliations, calibration, corrections, stage records, and historical snapshots.

Items are classified by primary role. Cross-cutting files are noted explicitly rather than duplicated.

Canonical runtime/configuration paths remain in their existing locations. This taxonomy is an organization layer, not a capability change or history rewrite.
