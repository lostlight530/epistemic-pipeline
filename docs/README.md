# Documentation Taxonomy

This directory classifies the current repository into three reading classes without deleting, duplicating, or rewriting existing repository history.

1. [Source and explanation](01-source-and-explanation/README.md) — implementation surfaces and documents that explain current behavior.
2. [Examples and contracts](02-examples-and-contracts/README.md) — machine/project contracts, examples, operator guidance, and usage constraints.
3. [Maintenance and audit](03-maintenance-and-audit/README.md) — maintenance rules, dated reconciliations, calibration, corrections, stage records, and historical snapshots.

Canonical runtime/configuration paths remain in their existing locations. This taxonomy is an organization layer, not a capability change or authority rewrite.
