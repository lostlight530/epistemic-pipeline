# Frontier Research Stage Handoff — Stage G / 2025-Q3

## Eligible findings
- adversarial agent evaluation benefits from trajectory-level policy/action/effect evidence;
- expected execution plans are useful evidence objects for multi-tool evaluation;
- tool order, arguments, intermediate state, and completion conditions should remain inspectable;
- partial observability makes task-time observation/memory state materially relevant;
- very long traces increase the need to distinguish retained evidence from later/current state.

## Unsafe generalization
- benchmark policy violation => production incident;
- red-team attack success => universal exploitability;
- execution-plan match => scientific truth;
- benchmark success => general competence;
- long trace => correct/complete causal trace;
- paper result => independent reproduction.

```text
handoff != acceptance
trace != truth
plan match != scientific adjudication
current state != task-time state
```
